# Apro — Modern Business Banking & Spend Management

A modern, responsive landing page mini-project built based on high-fidelity design specifications for business banking, spend management, and high-yield treasury platforms.

![Apro Landing Page Preview](https://images.unsplash.com/photo-1559526324-4b87b5e36e44?auto=format&fit=crop&w=1200&q=80)

---

## 🚀 Live Demo & Overview

* **GitHub Repository:** [https://github.com/Jatin2140/practice](https://github.com/Jatin2140/practice)
* **Design Inspiration:** Modern fintech & business banking design system (Apro).

### Key Features Implemented:
1. **Pixel-Accurate Hero Bento Grid:**
   - **Business Checking Accounts:** Architectural teal container with abstract brand badges and a glassmorphic floating account balance breakdown (`$254,783.37`).
   - **Business Credit Cards:** Minimalist sand-beige card preview with dual oval tokens and live spend balance tracker (`$7,880 Spent` vs `$3,430 Remaining`).
   - **AproTreasury Section:** Highlighting up to 5.30% APY return with branded dark green geometric motifs.
2. **Interactive Treasury Yield Calculator:**
   - Real-time slider from `$10,000` to `$2,000,000+`.
   - Quick preset buttons (`$50K`, `$250K`, `$500K`, `$1M`).
   - Computes annual and monthly yields at 5.30% APY and compares against traditional banks (0.01%).
3. **Responsive Navigation & Mobile Drawer:**
   - Modern pill-shaped CTA buttons.
   - Fully responsive hamburger navigation for mobile screens.
4. **Interactive Accordion FAQs:**
   - Smooth expand/collapse answering banking, FDIC sweep coverage, and Treasury mechanics.
5. **Brand Polish & Typography:**
   - Google Fonts: **Plus Jakarta Sans** (clean body) & **Outfit** (modern geometric headings).
   - Lucide Icons library integration.

## 🛠️ Tech Stack

* **HTML5:** Semantic, accessible markup.
* **Tailwind CSS:** Modern utility-first styling with custom palette matching the Figma/Dribbble spec.
* **JavaScript (ES6+):** Pure vanilla JavaScript for zero-dependency reactivity (calculator, mobile drawer, accordions).
* **Lucide Icons:** Modern feather icon suite.

## 💻 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jatin2140/practice.git
   cd practice
   ```

2. **Open `index.html`:**
   - Simply double click `index.html` in your file explorer to open it in any web browser.
   - Or run with a local server (e.g. VS Code Live Server or Python):
     ```bash
     python3 -m http.server 3000
     ```
     Then open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploy to GitHub Pages (One-Click)

To enable live hosting directly on GitHub:
1. Go to your repository settings: `https://github.com/Jatin2140/practice/settings/pages`
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select `main` branch and `/ (root)`, then click **Save**.
4. Your site will be live at: `https://jatin2140.github.io/practice/`
